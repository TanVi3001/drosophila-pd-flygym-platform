## Cần lưu ý trước khi duyệt

- `.gitignore` hiện có pattern `.pytest-tmp*/` cho thư mục, nhưng file `.pytest-tmp-release-gate-current.json` vẫn lọt vào status; nếu duyệt `gitignore`, nên thêm pattern file phù hợp.
- `data/2025_Connectivity_783.parquet` và các `data/plastic_weights*.pt` là artifact lớn. Nếu cần reproduce từ clone sạch, phải chốt nơi lưu ngoài Git và checksum/URL/commit trong release manifest; không nên âm thầm bỏ chúng khỏi provenance.
- `pink1_locomotion.json` root có cùng experiment id với các output có timestamp khác; tôi đề xuất drop bản không provenance này, không xoá file ở bước hiện tại.
- Các file ngoài repo do người dùng cung cấp (`C:\Users\JOHAN\Downloads\...`) không thuộc `git status` và không nằm trong bảng này.
- File báo cáo này được tạo sau snapshot status theo yêu cầu; nó là artifact triage mới và chưa nằm trong inventory baseline ở trên.
