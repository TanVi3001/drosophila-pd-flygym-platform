# Tài liệu kỹ thuật tiếng Việt

Thư mục này giải thích kiến trúc và quy trình phát triển của Fly Studio cho
người đọc tiếng Việt. Source code và API tiếng Anh vẫn là nguồn chuẩn; tài
liệu này phải được cập nhật cùng mỗi thay đổi kiến trúc.
