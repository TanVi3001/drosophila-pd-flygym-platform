# Cover Letter

To the Editors,

Please consider the frozen repository version 1.0.0 package for review as a
computational research software and manuscript submission:

- Repository: `https://github.com/tuanwannafly/drosophila-pd-flygym`
- Release: `v1.0.0`
- Canonical manuscript source: `docs/report/final_report.md`
- Final report PDF: `dist/Drosophila_PD_FlyGym_Final_Report.pdf`
- Final report DOCX: `dist/Drosophila_PD_FlyGym_Final_Report.docx`
- Final report manifest: `dist/final_report_manifest.json`

The submission describes a reproducible computational Drosophila locomotion
phenotype framework using FlyGym, NeuroMechFly, and MuJoCo. The repository
preserves frozen evidence JSON files, analysis figures, CSV tables, final
report artifacts, release notes, citation metadata, and an MIT license.

Scientific scope is deliberately limited. The work reports a
computational/phenomenological simulation framework. It does not claim
biological Parkinson's disease validation, dopamine equivalence, neuron-loss
equivalence, disease-severity mapping, biological rescue, mechanistic
equivalence, pharmacological treatment response, or inferential statistical
significance.

Journal-specific metadata, author affiliations, corresponding-author details,
submission category, suggested reviewers, and any required declarations should
be completed outside the frozen scientific manuscript unless a new authorized
revision is created.
