repository artifacts and final report files.

## Availability Boundary

The repository contains curated lightweight evidence and report artifacts.
Large raw artifacts should remain outside Git unless explicitly curated for an
external archive deposit. No DOI is declared unless one is minted by an actual
archive or publication event.
