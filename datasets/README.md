# Datasets

Large/raw inputs remain outside Git. The download guide and machine-readable
source record for the FlyGym Workbench are:

- [data/DOWNLOADS.md](../data/DOWNLOADS.md)
- [data/source_manifest.json](../data/source_manifest.json)

Each registered input includes its source, version or release context,
checksum, license/terms, and provenance. A fresh clone and the default CI
suite do not download external datasets.
